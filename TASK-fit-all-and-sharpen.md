## Step 1: diagnose the blur BEFORE changing anything
Measure and print, for the viewer, at 1440x900 (deviceScaleFactor 2) and 390x844 (deviceScaleFactor 3):
1. The on-screen size of the pouch in device pixels at default zoom and at maximum zoom.
2. The size of the texture actually uploaded to the GPU for the front and back (width x height), and where it comes from (a file, or a data URI inside pouch-art/pouch-textures.js). List the sizes in KB.
3. The renderer settings: setPixelRatio value, canvas width/height attributes vs its CSS size (a mismatch means the browser is upscaling the canvas = blur), texture.anisotropy, minFilter, magFilter, generateMipmaps, colorSpace/encoding, premultiplyAlpha, and the material (transparent, alphaTest).
4. The source resolution of each FRONT: find the best available original front image for each product (search assets/products/, the project root, products/, the scenes/ pouch cutouts; prefer originals with a pouch at least 1800px tall) and compare it with the 900x1400 pouch in the current texture. Never upscale. Report which products only have low-resolution fronts.
5. A sharpness baseline: capture a screenshot of the front view and of the back view of Rajma Masala at 1440x900 DPR 2 and compute the variance of the Laplacian on a fixed central crop (the text area) for each. Save the two screenshots in tools/blur-baseline/.
Print a short diagnosis table (cause, evidence, fix) and then continue.

## Step 2: build fitted backs for every product
1. Scan `incoming-backs/` recursively, both `REGULAR/` and `JAIN/`. Ignore `._` files and non-images. Reuse the filename normalisation in tools/replace-backs.py (trailing " 2" revision suffix, "panner" = "paneer", "&" = "and", "pind ke chole" = pind-ke-chhole) and add what the JAIN folder needs.
2. Mapping rule: match by normalised name to the product list. If a product has a file in BOTH folders, use the file from the folder that matches the product's Jain status in the product data (a Jain tag or category), and if that is unclear, leave the product unchanged and list it. Print the full mapping table (product slug, source file and folder). Products with no new back (and the thepla and combos, which have no pouch back) stay unchanged, listed.
3. Run the fit from tools/fit-backs.py (make it accept `all`) for every mapped product: crop the back to its alpha bounding box, scale non-uniformly to the front's pouch box, apply the front's outline mask (mirrored, because the viewer maps the back with u = 1 - u), edge-fill only the exposed pixels (top seal and bottom corners), never touch the print area. Per product print the stretch ratios; above 9% on either axis is a FAIL: leave that product's old back and list it.

## Step 3: sharp but light textures
Build the textures from the best sources, resampled ONCE (Lanczos) and never upscaled:
1. Target pixel size: compute from Step 1 how many device pixels the pouch needs at maximum zoom (on-screen height x min(devicePixelRatio, 2)), add 15 percent, and round up. Cap at 2048px on the long side. Expect roughly 1100x1750 pouch on a 1280x2000 canvas for desktop and about 800x1250 for mobile. Output both sizes: `*-1280.webp` and `*-800.webp`.
2. Format: WebP with the highest sensible quality that fits the budget, method 6, sharp_yuv enabled, alpha_quality 90 or better (edges must stay crisp), no chroma subsampling artefacts around small text. Budget: each texture (front or back) at most 300 KB for the desktop size and 150 KB for the mobile size. Start at quality 88 and step down only as far as needed. Never use JPEG for the final textures. Do not apply sharpening filters to the artwork (resampling only); a very light unsharp mask (radius 0.6, amount 40 percent) after the final downscale is allowed ONLY if the sharpness metric needs it, and say if you used it.
3. Fronts: regenerate each front texture from its best source (Step 1.4) at the same sizes and quality. If a product's only front source is the 900x1400 version, keep it at its native resolution and list it as "front limited by source resolution".
4. Write the files to `pouch-art/tex/<slug>-front-1280.webp`, `-front-800.webp`, `<slug>-back-1280.webp`, `-back-800.webp`. Move the replaced `pouch-art/<slug>-back-processed.png` and `<slug>-back.webp` to `_old-backs/pouch-art/`.
